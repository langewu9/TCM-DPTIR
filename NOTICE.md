# Provenance and attribution

The GCADTI model component in this codebase was adapted and extended within the TCM-DPTIR/DTL-SRNet research workflow from the GCADTI component associated with the DTLCDR project. The current source includes project-specific data handling, training utilities, and interaction-mode experiments; it is not a copy of the full DTLCDR or DTLACDR software package.

The upstream DTLCDR source available in the project workspace did not include an explicit license file.
